# melonDS Ounce Interactive ROM Runner\n\nFirst bootable emulator frontend target on Switch 2 (Ounce). Combines the validated core engine and the verified OunceVK EGL/GLES dual-screen presentation pipeline.\n\n## Build Instructions\n\nFrom your Windows PowerShell inside the Docker container at `/work`:\n\n```sh\nsource \"$DEVKITPRO/switch2vars.sh\"\naarch64-none-elf-cmake -S ounce/runner -B build-ounce-runner -DCMAKE_BUILD_TYPE=Debug\ncmake --build build-ounce-runner --target ounce-runner-nro --parallel 1\n```\n\nGenerated binary: `build-ounce-runner/melonds-ounce-runner.nro`.\n\n## SD Card Setup\n\n1. Copy `melonds-ounce-runner.nro` to `/switch/melonds-ounce/melonds-ounce-runner.nro` on your SD card.\n2. Place a valid Nintendo DS homebrew or test ROM at:\n   `/switch/melonds-ounce/boot.nds`\n3. Launch `melonds-ounce-runner` via the Switch 2 homebrew menu.\n\n## Controls\n\n| Switch 2 Input | DS Action |\n|---|---|\\n| A / B / X / Y | DS Face Buttons |\n| D-Pad | DS Directional Pad |\n| L / R | DS Bumpers |\n| Plus | DS Start |\n| Minus | DS Select |\n| Touchscreen (Bottom Screen area) | DS Stylus Touch |\n| **Plus + Minus (together)** | **Clean Exit to Homebrew Menu** |\n\n## Logging\n\nWrites detailed diagnostic logs to:\n`sdmc:/melonds-ounce-runner.log`\n
